## 📥 Instalasi

Clone repository:

```bash
git clone https://github.com/kudalaut01/domaswap.git
cd domaswap
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Menjalankan Project

```bash
node doma.js
```

atau

```bash
npm start
```
